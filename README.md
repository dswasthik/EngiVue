# EngiVue

AI-assisted engineering and industrial vision workspace.

## Planned MVP

- Industrial image upload and inspection
- OpenCV.js preprocessing and object analysis
- Calibration and measurement
- Defect and difference detection
- AI-assisted validated workflows
- Batch image processing and CSV export
- Initial DICOM viewer support

## Planned stack

- Next.js, React and TypeScript
- Tailwind CSS and shadcn/ui
- OpenCV.js and Canvas/WebGL
- ASP.NET Core Web API with C#
- Entity Framework Core with SQL Server LocalDB

## Repository layout

The application will be organized into frontend, API, shared schemas, processing tools, workflows, tests and documentation as implementation begins.
